# YAPIR - Your Pair AI Reviewer

YAPIR is an AI-powered code review platform that automatically reviews pull requests and provides feedback on code
changes. It integrates with Git providers like GitHub and GitLab to streamline the code review process with:
- Your rules
- Your Git
- Your AI provider
- Your models
